Базовый бэкенд-сервис для системы бронирования номеров в отелях. Проект предоставляет REST API для управления номерами, пользователями и бронированиями.

## 🛠 Технологический стек

* **Язык программирования:** Java (версия 21)
* **Фреймворк:** Spring Boot (Spring Web, Spring Data JPA)
* **Сборщик проекта:** Maven
* **База данных:** PostgreSQL
* **Контейнеризация:** Docker / Docker Compose
* **Тестирование API:** Postman
